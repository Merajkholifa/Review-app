# পুনরাবৃত্তি ট্র্যাকার — GitHub-এ আপলোড করার নিয়ম

এই zip-এ আছে: `index.html` (আপনার পুরো অ্যাপ) + আইকন ফাইলগুলো + `sw.js` (সার্ভিস ওয়ার্কার), আর সব লিংক আগে থেকেই HTML-এর ভিতরে বসানো আছে। শুধু আপলোড করলেই চলবে।

## আগে "Install" আসছিল না কেন?
`site.webmanifest`-এ আইকনের path `/android-chrome-192x192.png` এভাবে (শুরুতে `/` দিয়ে) লেখা ছিল, যেটা শুধু তখনই কাজ করে যখন সাইট ডোমেইনের একদম রুটে থাকে। কিন্তু GitHub Pages-এ আপনার সাইট থাকে `/repo-নাম/` এই সাবফোল্ডারে, তাই আইকন ফাইল খুঁজে পাচ্ছিল না — ফলে ম্যানিফেস্ট invalid হয়ে যাচ্ছিল আর ফোন শুধু "Add shortcut" দেখাচ্ছিল, আসল "Install" অপশন না। এই ভার্সনে path ঠিক করা হয়েছে, আর একটা `sw.js` (সার্ভিস ওয়ার্কার) যোগ করা হয়েছে — কিছু অ্যান্ড্রয়েড Chrome ভার্সনে এটা ছাড়া "Install" অপশন আসে না।

## ধাপ ১ — রিপোজিটরি বানান
1. https://github.com এ লগইন করুন
2. উপরে ডানে `+` আইকনে ক্লিক করে **New repository** সিলেক্ট করুন
3. একটা নাম দিন, যেমন `revision-tracker`
4. **Public** সিলেক্ট করে **Create repository** চাপুন

## ধাপ ২ — ফাইলগুলো আপলোড করুন
1. রিপোর পেজে **Add file → Upload files** এ ক্লিক করুন
2. এই zip ফাইলটা extract (unzip) করে ভেতরের সবগুলো ফাইল (`index.html`, `sw.js`, `favicon.ico`, বাকি PNG গুলো, `site.webmanifest`) — সব একসাথে ড্র্যাগ করে ছেড়ে দিন
3. নিচে **Commit changes** বাটনে ক্লিক করুন

**আগে থেকে রিপো থাকলে:** পুরনো `site.webmanifest` আর `index.html` ফাইলদুটো এই নতুনগুলো দিয়ে ওভাররাইট (উপরে আপলোড করলে অটো হয়ে যায়) করুন, আর `sw.js` নতুন করে যোগ করুন।

## ধাপ ৩ — লাইভ লিংক চালু করুন (GitHub Pages)
1. রিপোর **Settings** ট্যাবে যান
2. বাঁ পাশের মেনু থেকে **Pages** সিলেক্ট করুন
3. **Branch** এর নিচে `main` সিলেক্ট করে, ফোল্ডার `/ (root)` রেখে **Save** চাপুন
4. ১-২ মিনিট পর একটা লিংক দেখাবে, যেমন:
   `https://<আপনার-ইউজারনেম>.github.io/revision-tracker/`

## ফোনে ইনস্টল করার সময়
1. Chrome দিয়ে লিংকটা খুলুন
2. পুরনো কোনো ভার্সন ক্যাশে থেকে গেলে সমস্যা করতে পারে, তাই একবার হার্ড রিফ্রেশ করুন বা কয়েক সেকেন্ড অপেক্ষা করুন
3. তিন-ডট মেনু থেকে এবার "Install app" বা "অ্যাপ ইনস্টল করুন" অপশন আসা উচিত — যদি শুধু "Add to Home screen" দেখায়, একবার পেজ রিলোড করে আবার চেষ্টা করুন
