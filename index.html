ব্যাকআপ
এক্সপোর্ট করলে আপনার সব চ্যাপ্টার আর পরীক্ষার ডেটা একটা ফাইলে সেভ হয়ে ডাউনলোড হবে। ইমপোর্ট করলে সেই ফাইলের ডেটা বর্তমান ডেটার সাথে যোগ (merge) হবে — আগের কিছু মুছে যাবে না, আর একই চ্যাপ্টার/পরীক্ষা আগে থেকে থাকলে সেটা দুইবার যোগ হবে না।
ডিভাইস সিঙ্ক (GitHub)
সিঙ্ক এখনো সেটআপ করা হয়নি।
এই ফিচার আপনার নিজের একটা প্রাইভেট GitHub রিপো-কে স্টোরেজ হিসেবে ব্যবহার করে, যাতে একাধিক ডিভাইস থেকে একই ডেটা দেখা যায়। টোকেন বানানোর নিয়ম: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → নতুন টোকেন বানান, শুধু ঐ একটা রিপোর জন্য Contents: Read and write পারমিশন দিন। টোকেনটা শুধু আপনার এই ব্রাউজারেই সেভ থাকবে, কারো সাথে শেয়ার করবেন না।

এখন ডিলিট করাও সিঙ্ক হয় — কোনো ডিভাইসে একটা চ্যাপ্টার/পরীক্ষা মুছে ফেললে, সিঙ্কের সময় সেটা বাকি ডিভাইসেও মুছে যাবে।
